**Crucial source-status caveat:** the actual CSV has no standalone `quality` column. The normalizer must preserve this absence and never invent release/finality or revision status. On current data, it appends the explicit `source_quality_field_not_provided` status. Release- and revision-status semantics require separate Destatis documentation and publication-time confirmation.

The updated normalization parser accepts both documented `YYYY-MM` fixtures and authentic `JAHR+MONATxx` rows, while validating the strict structure. It continues to reject unknown month codes, inconsistent adjustment, missing values without explicit source meaning, duplicate periods and mixed reference bases.
